Friendar 便利なコード集
========================

HTMLは画面、CSSは見た目、JavaScriptは動き、Firebaseはデータを担当します。
必要な行だけコピーして使ってください。

## HTMLの早見表

| 書き方 | 役割 | 例 |
| --- | --- | --- |
| `<h1>` | 大きな見出し | `<h1>マイページ</h1>` |
| `<h2>` | 小見出し | `<h2>チーム</h2>` |
| `<p>` | 文章 | `<p>こんにちは</p>` |
| `<strong>` | 太字・強調 | `<strong>重要</strong>` |
| `<span>` | 文字を囲む | `<span id="name"></span>` |
| `<div>` | 部品をグループ化 | `<div>内容</div>` |
| `<input>` | 入力欄 | `<input id="name" type="text">` |
| `<button>` | ボタン | `<button id="save">保存</button>` |
| `<a>` | 別ページへのリンク | `<a href="mypage.html">マイページ</a>` |
| `<form>` | 入力フォーム | `<form id="loginForm">...</form>` |
| `id` | JavaScriptから指定する名前 | `<p id="message"></p>` |
| `class` | CSSでまとめて指定する名前 | `<p class="notice"></p>` |

## CSSの早見表

| 書き方 | 何をする？ | 例 |
| --- | --- | --- |
| `color` | 文字色 | `color: red;` |
| `background` | 背景色 | `background: white;` |
| `font-size` | 文字の大きさ | `font-size: 20px;` |
| `font-weight` | 文字の太さ | `font-weight: bold;` |
| `text-align` | 文字の位置 | `text-align: center;` |
| `margin` | 外側の余白 | `margin: 20px;` |
| `padding` | 内側の余白 | `padding: 12px;` |
| `border` | 枠線 | `border: 1px solid gray;` |
| `border-radius` | 角を丸くする | `border-radius: 8px;` |
| `display: flex` | 横並びなどにする | `display: flex;` |
| `display: grid` | 格子状に並べる | `display: grid;` |
| `gap` | 部品同士の間隔 | `gap: 10px;` |
| `width` | 幅 | `width: 100%;` |
| `max-width` | 最大幅 | `max-width: 760px;` |

## JavaScriptの早見表

| 書き方 | 何をする？ | 例 |
| --- | --- | --- |
| `const` | 変わらない変数 | `const name = "瑛佑";` |
| `let` | 変わる変数 | `let count = 0;` |
| `getElementById` | HTML要素を取得 | `document.getElementById("name")` |
| `textContent` | 文字を表示 | `element.textContent = "こんにちは";` |
| `value` | 入力値を取得 | `input.value` |
| `trim()` | 前後の空白を削除 | `input.value.trim()` |
| `addEventListener` | クリックなどを検知 | `button.addEventListener("click", save)` |
| `if` | 条件で処理を分ける | `if (user) { ... }` |
| `forEach` | 配列を1個ずつ処理 | `items.forEach((item) => { ... })` |
| `push()` | 配列に追加 | `items.push(newItem)` |
| `length` | 文字数・件数 | `items.length` |
| `includes()` | 含まれるか確認 | `text.includes("学校")` |
| `toUpperCase()` | 大文字に変換 | `code.toUpperCase()` |
| `` `${}` `` | 文字を組み合わせる | `` `${name}さん` `` |

## 文字の早見表

| 書き方 | 何をする？ | 例 |
| --- | --- | --- |
| `replace()` | 文字を1か所置換 | `text.replace("赤", "青")` |
| `replaceAll()` | 文字を全部置換 | `text.replaceAll("犬", "猫")` |
| `split()` | 文字を配列に分割 | `"A,B".split(",")` |
| `join()` | 配列を文字に結合 | `items.join(" / ")` |
| `startsWith()` | 先頭の文字を確認 | `text.startsWith("今日")` |
| `endsWith()` | 最後の文字を確認 | `text.endsWith("ます")` |
| `toLowerCase()` | 小文字に変換 | `name.toLowerCase()` |

## Firebaseの早見表

| 書き方 | 何をする？ | 例 |
| --- | --- | --- |
| `doc()` | 保存場所を指定 | `doc(db, "users", uid)` |
| `getDoc()` | 1つのデータを取得 | `await getDoc(userRef)` |
| `setDoc()` | データを保存・更新 | `await setDoc(userRef, data)` |
| `arrayUnion()` | 配列に追加 | `arrayUnion(uid)` |
| `snapshot.exists()` | データの有無を確認 | `if (snapshot.exists())` |
| `snapshot.data()` | データの中身を取得 | `const data = snapshot.data()` |
| `merge: true` | 既存データを残して更新 | `{ merge: true }` |

## よく使うセット

| やりたいこと | コード |
| --- | --- |
| HTML要素を取得 | `const message = document.getElementById("message");` |
| 入力値を表示 | `message.textContent = input.value.trim();` |
| ボタンを押して表示 | `button.addEventListener("click", () => message.textContent = "完了");` |
| 入力中に表示 | `input.addEventListener("input", () => preview.textContent = input.value);` |
| ユーザー名を表示 | `usernameElement.textContent = userData.username || "名前未設定";` |

## 注意

ユーザーが入力した文字を表示するときは、`innerHTML`より`textContent`を使います。
`textContent`なら、入力文字がHTMLとして実行されるのを防げます。
